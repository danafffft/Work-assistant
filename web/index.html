Почнімо з трьох кроків

  1. Відкрийте класичний Outlook і підключіть його кнопкою в меню.
  2. Заповніть локальний профіль та оберіть робочий час.
  3. За потреби підключіть Jira і Teams. Вони не обов’язкові для локальних доручень.

Ваш профіль і підключення

Один робочий email для всіх сервісів. Реєстрація на зовнішньому сервері не потрібна.

Email і адреса Jira зберігаються лише на цьому комп’ютері. Токен — лише в пам’яті до закриття або відключення Outlook. Для Jira Cloud: email та API token; для Jira Server / Data Center: персональний access token. Пароль не потрібен.
